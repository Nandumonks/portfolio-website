# portfolio-website Nandumon KS

personal portfolio website showcasing my profile, technical skills, certifications, and contact information. Built with HTML, CSS, and vanilla JavaScript, without requiring a front-end framework.
✨ Features
- Responsive design for desktop and mobile screens
- Light and dark themes with a theme toggle
- Mobile navigation menu
- Smooth scrolling between page sections
- Scroll-reveal animations for selected content
- Active navigation highlighting based on the visible section
- Developer-inspired interface with a code-editor-style header and profile card
- Certifications section with links to certificates
- Contact section with email and social links
- Accessibility considerations, including visible keyboard focus and reduced-motion support
🛠️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Space Grotesk, Inter, and JetBrains Mono
📁 Project Structure
portfolio/
├── index.html    # Website structure and content
├── style.css     # Styling, themes, layout, and responsive design
├── script.js     # Theme toggle, mobile menu, and scroll interactions
└── README.md     # Project documentation
🚀 Run Locally
No package installation or build step is required.
1. Clone this repository:
   git clone https://github.com/Nandhu-Sunil/portfolio-website.git
2. Open the project folder:
   cd YOUR-REPOSITORY-NAME
3. Open index.html in your browser.
   Alternatively, use the Live Server extension in Visual Studio Code for local development.
Replace YOUR-REPOSITORY-NAME in the clone command with your actual GitHub repository name.

🌐 Deploy with GitHub Pages
1. Push index.html, style.css, and script.js to your GitHub repository.
2. Open the repository on GitHub and go to Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select your main branch and the / (root) folder, then save.
5. Wait for GitHub Pages to publish the site. Your website URL will appear in the Pages settings.
✏️ Customization
- Update your name, introduction, skills, certifications, and contact details in index.html.
- Change colors, typography, spacing, and responsive layouts in style.css.
- Customize theme switching, mobile navigation, and scroll interactions in script.js.
- Replace placeholder social links with your actual profile URLs.
